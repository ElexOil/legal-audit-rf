## 💡 Концепция

**legal-audit-rf** — это Claude Code skill для инженерного аудита сайта на соответствие законодательству РФ. Он не заменяет юриста, но закрывает 80% типовых нарушений, которые автосканер РКН ловит в первую очередь: отсутствие чекбокса согласия, шаблонная политика, трекеры без cookie-баннера, авторизация через зарубежные OAuth без альтернативы для РФ-пользователей.

Skill работает в паре со сканером `scripts/scan.py` (только стандартная библиотека Python): сканер собирает сигналы по коду сайта и живому URL, а Claude Code интерпретирует их по чек-листу и выдаёт отчёт с конкретными правками.

## ✨ Возможности

| Возможность | Описание |
|-------------|----------|
| 🔍 **Сканер сигналов** | `scan.py` ищет трекеры, формы сбора ПД, cookie-баннер, юр-страницы, реквизиты, HTTPS — без внешних зависимостей |
| 📋 **Чек-лист 16 пунктов** | Политика, согласие, cookie, трансграничка, локализация, РКН, реквизиты, минимизация, HTTPS, реклама, возрастная маркировка, гос. язык, Meta, оферта, возврат, авторизация |
| ⚖️ **Справочник штрафов** | КоАП ст. 13.11 (18 частей), ст. 13.55 (авторизация), УК ст. 272.1/137 — с суммами и условиями |
| 🔐 **Авторизация РФ-пользователей** | Проверка по 149-ФЗ (ФЗ № 199 от 26.06.2026, в силе с 07.07.2026): `+7`, ЕСИА, ЕБС, российские ID-системы, собственная авторизация; штрафы до 1,4 млн ₽ |
| 📝 **Шаблон отчёта** | Структурированный вывод: резюме → таблица статусов → организационные задачи → правки в коде |
| 🛡️ **Безопасность** | TLS, HSTS, CSP, CORS, утечки ключей в JS, `security.txt` |
| 📄 **Шаблоны документов** | Приказ о назначении ответственного за ПДн, Политика обработки ПДн |

## 🚀 Быстрый старт

### Claude Code skill

Положите папку в `.claude/skills/legal-audit-rf/` (проектный) или `~/.claude/skills/` (глобальный):

```bash
git clone https://github.com/ElexOil/legal-audit-rf.git ~/.claude/skills/legal-audit-rf
```

Затем в Claude Code: «проверь сайт example.ru на 152-ФЗ» — skill подхватится по описанию.

### Сканер напрямую

```bash
python scripts/scan.py /путь/к/проекту https://example.ru
```

Вывод — сводка сигналов; интерпретация — по чек-листу `SKILL.md`.

<details>
<summary>⚙️ Что проверяет сканер</summary>

| Группа | Что ищет |
|--------|----------|
| **Трекеры** | GA4, Яндекс.Метрика, Вебвизор, VK Pixel, Facebook Pixel, Google Fonts, Telegram |
| **Формы сбора ПД** | Поля телефона/email/ФИО/адреса, чекбоксы согласия, предзаполненные (`checked`) |
| **Юр-страницы** | Политика, согласие, cookie, ИНН, ОГРН, локализация, трансграничка, дата редакции, оферта, возврат |
| **Запрещённое** | Ссылки на Facebook, Instagram (Meta запрещена в РФ) |
| **Живой URL** | Протокол (HTTPS обязателен), сигналы на живой странице |

</details>
