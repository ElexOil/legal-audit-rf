# Правила авторизации на интернет-ресурсах РФ и КоАП РФ ст. 13.55

> Справочник для скилла `legal-audit-rf` по материалам информационной справки Зарцын & Партнёры о законопроекте № 1069392–8, принятом Государственной Думой в третьем чтении 09.06.2026. Не юридическая консультация: перед внедрением сверить вступление закона в силу и актуальную редакцию 149-ФЗ/КоАП РФ.

## Суть требования

Если сайт, страница сайта, информационная система, приложение или программа работает в сети Интернет на территории РФ и предоставляет доступ к информации пользователям, **прошедшим авторизацию**, то для пользователей, находящихся на территории РФ, авторизация должна проводиться одним из способов, предусмотренных 149-ФЗ «Об информации, информационных технологиях и о защите информации».

Нарушение выделено в новую **ст. 13.55 КоАП РФ**: неисполнение обязанности проводить авторизацию разрешённым способом.

## Штрафы по ст. 13.55 КоАП РФ

| Субъект | Штраф |
|---|---:|
| Граждане | 10 000–20 000 ₽ |
| Должностные лица | 30 000–50 000 ₽ |
| Юридические лица | 500 000–700 000 ₽ |

## Разрешённые способы авторизации

| Способ | Что проверять при аудите |
|---|---|
| Номер телефона российского оператора связи | Авторизация по абонентскому номеру оператора подвижной радиотелефонной связи с кодом `+7`. |
| ЕСИА / «Госуслуги» | Вход через федеральную государственную информационную систему ЕСИА. |
| ЕБС | Вход через государственную систему идентификации и аутентификации физических лиц с использованием биометрических персональных данных. |
| Российская ID-система | Система авторизации принадлежит гражданину РФ без второго гражданства или контролируемому РФ юрлицу и соблюдает требования кибербезопасности по ст. 16 149-ФЗ. Контроль — право решающего голоса, обычно более 50% акций/долей. Примеры для проверки: VK ID, Сбер ID и аналогичные российские ID-системы. |
| Собственная авторизация сайта | В справке отдельно отмечено, что для целей авторизации допустимо использовать собственную платформу сайта, включая email пользователя, зарегистрированный на иностранном домене. |

## На каких пользователей распространяется

Требование относится к пользователям, находящимся на территории РФ. Для иностранных пользователей могут применяться иные способы авторизации, но аудитору нужно понять, как сайт определяет российский сегмент.

Практические сигналы местонахождения пользователя:

- явный выбор страны/места фактического нахождения при регистрации;
- номер телефона, особенно российский код `+7`;
- платёжные данные, например российская банковская карта;
- IP-адрес — только как дополнительный, не основной признак.

## Старые аккаунты и обратная сила

По общему правилу ст. 1.7 КоАП РФ закон, устанавливающий или отягчающий административную ответственность, обратной силы не имеет. Поэтому штрафные санкции за действия до вступления нормы в силу не применяются, а требовать от всех ранее зарегистрированных пользователей перерегистрации или корректировки данных в личном кабинете само по себе не требуется.

## Что делать с зарубежной автоматической авторизацией

Если используется автоматическая авторизация через зарубежные сервисы — например Google ID, Apple ID и т.п. — это отдельный риск для российских пользователей.

Рекомендуемые действия для отчёта аудита:

1. Ограничить технологическую реализацию автоматической авторизации через зарубежные сервисы для пользователей из РФ.
2. Если в личном кабинете нет иных подтверждённых данных — email/телефона, — предусмотреть перерегистрацию или привязку разрешённого способа авторизации.
3. Для новых российских пользователей включить разрешённые способы авторизации: `+7`, ЕСИА, ЕБС, российскую ID-систему или собственную авторизацию сайта.

## Быстрый чек для аудитора

- [ ] На сайте/в приложении есть регистрация или личный кабинет.
- [ ] Для пользователей из РФ доступен хотя бы один разрешённый способ авторизации.
- [ ] Зарубежные OAuth/ID-провайдеры не являются единственным способом входа для пользователей из РФ.
- [ ] Есть логика определения/самодекларации местонахождения пользователя.
- [ ] Старые аккаунты не принудительно ломаются без необходимости, но для автоматической зарубежной авторизации предусмотрен безопасный переход.
- [ ] В отчёте указаны штрафы по КоАП РФ ст. 13.55 и конкретные способы исправления.
